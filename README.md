📝 Todo List Application

 📌 Description

This is a simple GUI-based Todo List application built using Python and Tkinter.
It helps users manage daily tasks by adding, deleting, and marking tasks as completed.
Task data is stored using a CSV file with the help of Pandas.

---

 🚀 Features

* Add new tasks
* Delete tasks
* Mark tasks as completed ✔
* Data saved in CSV file
* Simple and user-friendly interface

---

 🛠 Technologies Used

* Python
* Tkinter (GUI)
* Pandas (Data Handling)
